# Remote Mapper guides

Each guide is a few numbered steps with a short screen recording.

| Guide | Covers |
|---|---|
| [Getting started](getting-started.md) | add a remote, add the card, assign the first action |
| [Layout and looks](layout-and-looks.md) | grid and canvas layouts, swapping buttons, display modes, colours |
| [Scenes](scenes.md) | capture the room's current state as a scene, re-snapshot it later |
| [Automations](automations.md) | turn a button into a native HA automation, or build one for the whole remote |
| [Existing automations](existing-automations.md) | link or absorb what you already have, re-import, hand the remote back |

Card options in YAML and the supported remote types are in the main
[README](../../README.md).
